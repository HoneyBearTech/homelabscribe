# Support

## Getting help

- **How do I…?** Read the [documentation](docs/README.md), then open a [GitHub Discussion or Issue](https://github.com/HoneyBearTech/homelabscribe/issues) with the `question` label.
- **Something is broken:** open a bug report and attach `homelabscribe doctor` output.
- **Security issue:** follow [SECURITY.md](SECURITY.md); do not post it publicly.

HomelabScribe is maintained by one person in spare time. Expect a first reply within about a week; there is no guaranteed response time for free support.

## Supported versions and maintenance window

| Version | Status |
| --- | --- |
| Latest release | Supported: bug and security fixes |
| Previous minor release | Security fixes only, for 90 days after the next minor ships (once 1.0 is out) |
| Anything older / pre-1.0 older minors | Not supported: please upgrade |

Docker and Python versions: the project follows upstream support. Python 3.11 is supported until its end of life in October 2027.

## Support for the Pro tier

Pro license holders can ask for help the same way; Pro features are documented in the same `docs/`.
